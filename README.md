# Power Plant Output Prediction

Predicts power plant energy output using Artificial Neural Network (ANN) Regression.

## Dataset
powerplant_data.csv - Combined Cycle Power Plant data
- Features: Temperature (AT), Exhaust Vacuum (V), Ambient Pressure (AP), Relative Humidity (RH)
- Target: Energy Output (PE)

## Workflow in this notebook
1. Data Loading & Visualization
2. Data Preprocessing - Feature Scaling
3. Train Test Split
4. Model - Artificial Neural Network (ANN) Regression
5. Prediction & Evaluation (MAE, RMSE, R2 Score)

## Tech Stack
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn, TensorFlow / Keras

## How to Run
pip install pandas numpy matplotlib scikit-learn tensorflow
jupyter notebook ANN_Regression.ipynb
